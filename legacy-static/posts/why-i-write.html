写作是最好的思考方式

2026-06-03 技术 写作 / 思考

很多人以为，写作是先想清楚，再把结论写下来。但我越来越觉得，事实正好相反：你常常是在写的过程中，才把事情想清楚的。

大脑会骗你

在脑子里，一个想法可以毫不费力地"感觉很对"。但一旦你试着把它写成完整的句子，那些含糊的地方、逻辑的断层、站不住脚的假设，全都会暴露出来。

如果你不能把一件事写清楚，那很可能是你还没真正理解它。

一个小习惯

我现在养成了一个习惯：遇到想不明白的问题，就打开一个空白文档，逼自己用文字把它讲给一个"假想的读者"听。比如，解释一段代码为什么这样设计：

function greet(name) {
  // 简单，但写出来才发现边界情况：name 为空怎么办？
  return name ? `Hello, ${name}!` : "Hello, stranger!";
}

写着写着，问题往往就自己解开了。

所以，动笔吧

这就是写作的魔力——它不只是记录思考，它本身就是思考。下次再卡住的时候，别只在脑子里打转，试着写下来。
